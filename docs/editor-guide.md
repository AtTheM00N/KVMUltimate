# Editing the cinematic studio

## Homepage

Open Home in Gutenberg and use List View. The **Konnect studio journey** contains six locked chapter slots: Intro, Work, Services, Process, Studio and Contact. Select a chapter to edit its sidebar controls. All six are beats in one home-page scroll; the menu jumps to them within that journey. The canvas shows a representative still in Gutenberg, not an active 3D scene.

- Keep headings short. Bespoke Stencil is expressive. Omit the Description when the heading or artwork already communicates the point. Do not add numbered kickers, arrow controls, slash labels or progress ticks.
- The process heading is split at sentence boundaries into its visible words.
- Link controls are available for Intro, Work and Studio. Link URL accepts a local path such as `/contact/` or a normal HTTPS URL. Link text is editable separately.
- Fallback images can be replaced independently for desktop and mobile. Resetting a selection restores the original studio render. Posters are decorative because the nearby HTML supplies the information.
- Work can select up to two published projects. With both selectors on Automatic, portfolio Order determines the selection. Explicit selections are limited to those selected published records. Draft and private entries are never exposed. Production also excludes preview placeholders.
- Service chapter panels edit each service heading and description. An empty override uses the default copy. The dedicated Services page has its own service-copy controls.

Camera positions, portfolio opening and physical objects are defined in the scene source, not through page editing. Changing a poster does not alter the 3D model. Add real project Featured images to populate its two portfolio surfaces; retain readable project titles, service terms and alt text on the normal Work pages.

## Work and project pages

Use Projects → Add project. Add a title, service classifications, featured image, brief, scope and approach. Gallery controls accept WordPress image attachments. Optional empty sections disappear. Results require both actual supporting text and the verified/approved switch. Do not use that switch for speculative outcomes.

Preview placeholders can publish only in local/development environments. They remain hidden from production listings, scene selections and direct project URLs. Until approved work exists, the homepage uses original Konnect studio materials and an honest portfolio availability message.

## Enquiries and campaigns

Enquiries remain administrator-only records. Set the notification recipient and public email under Settings → Konnect. Configure authenticated mail delivery separately; a saved enquiry does not establish that email arrived. Notification failures are visible to administrators.

Campaign pages use the simplified Campaign template, normal HTML content, a studio still and the enquiry block. They contain no 3D journey or publisher-ad slots. Analytics and publisher providers remain disabled locally.

## Before publishing edits

Preview the page at a desktop width and on a phone. Check long headings, visible project labels, every CTA, image crops and the enquiry form. Review the static/reduced-motion version as well as the animated desktop version. Scene content must remain understandable without animation.
