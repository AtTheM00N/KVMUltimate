# Verification — 13 November 2026

## Automated checks

The production build and active 2D asset checks passed. Original artwork, including fourteen WebP posters and the retained signature SVG, totals **251,999 bytes**. The two JavaScript bundles total **46,067 bytes gzip**. Font names agree with Gutenberg configuration; the compiled frontend contains no model, WebGL renderer or decoder. These are transfer budgets, not field performance measurements.

Isolated WordPress 6.8.12 / PHP 8.3.36 checks passed for six editable chapter blocks, eight pages, project selection and filtering, private enquiries, validation, nonce protection, duplicate/rate limiting, email failure handling, native form fallback and explicit migration safety. Production checks passed for demo invisibility, blocked demo publishing, integration review gating and campaign ad exclusions. Full evidence is copied to docs/evidence/ when packaging.

The current lifecycle checks execute the actual scroll module with DOM/GSAP doubles: cleanup restores author styles, removes listeners/observers and cancels pending frames; repeated disposal is safe; partial setup failure restores static presentation. Tests of the real base module also confirm that reduced-motion and Save-Data preferences prevent the deferred scroll import. These are unit checks, not a browser preference-emulation test.

## Browser review

The loopback preview was reviewed in the in-app browser. Homepage checks covered 320, 390, 768, 1024 and 1440 pixel widths; no horizontal document overflow was observed. The work index, services, contact form, original project detail and studio composition were inspected. About, Contact, Campaign and project detail were also checked at 320 pixels after correcting the supporting column stacking. No broken images were reported in that supporting-page pass.

Menu opening, initial Close focus, Escape, focus restoration and the Contact chapter jump were observed. The homepage's scroll module reached ready state, and its canvas/moving-K markup was absent. Console inspection after the final reload returned no warnings or errors.

Temporary fixtures served the same rendered homepage with all script tags removed and with substantially longer heading/body copy. At 320 pixels the fallback navigation and complete artwork remained visible, copy flowed naturally and neither fixture overflowed horizontally. The fixtures do not write WordPress content and are not packaged. Their form behaviour is covered by the isolated native-POST tests above.

Screenshots are in artifacts/editorial-desktop.jpg and artifacts/editorial-mobile.jpg.

## Limits and release

The browser's actual reduced-motion preference was not overridden; static rendering and the preference gate were checked separately as described above. Real assistive technology, Gutenberg interaction, hosted email delivery, staging compatibility, field LCP/CLS and representative hardware performance still need launch review. No external deployment was performed.

The persistent preview is http://127.0.0.1:9400/ and binds only to loopback. Historical 3D verification is preserved in verification-3d-history.md and does not describe the current runtime.
